# Project development gate

For every task that modifies source code, tests, or behavior-changing configuration in this repository, read and follow `.codex/skills/nanovllm-milestone-development/SKILL.md` before making changes. This is mandatory for the mixed-batch project.

Read-only exploration, source explanation, and status reporting do not require the skill. Keep each implementation task to one milestone and preserve the skill's investigation, design, implementation, verification, and engineering-record lifecycle.
